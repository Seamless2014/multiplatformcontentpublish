# 多平台图文发布器 · 使用说明

> 一次编辑，把一篇图文分发到 **微信公众号 / 今日头条 / 知乎 / 百家号 / 小红书 / 百度贴吧 / 新浪微博**。
> 程序复用你浏览器里**已登录**的各平台会话，不保存你的账号密码，也不需要你重新登录各平台。

## 1. 它能做什么

| 能力 | 说明 |
|------|------|
| **一次编辑，多平台分发** | 一篇 Markdown 文章勾选多个平台，自动逐个填入各平台编辑器 |
| **复用已登录会话** | 直接接管你浏览器里已登录的账号，不需要在每个平台重新扫码 |
| **两种模式** | **草稿模式**（只填表保存草稿，安全默认）/ **直接发布**（点平台发布按钮） |
| **自动校验** | 发布前按各平台规则检查标题字数、正文长度、图片要求，不合规会拦截并提示 |
| **格式保留** | 标题、加粗、小标题、列表、表格等富文本格式保留；图片自动转存到平台 |
| **失败留证** | 失败任务自动截图，可在进度面板查看失败现场 |
| **任务持久化** | 发布任务记录保存，失败任务可一键重试 |

**重要前提**：本工具是「**自动化填表助手**」，不是「绕过平台风控的群发机器人」。
所有内容最终都通过你**自己已登录的账号**提交，平台该有的审核、限流、折叠规则照常生效。

## 2. 环境准备（首次使用，约 5 分钟）

### 2.1 启动服务

```bash
cd multi-publisher
npm install        # 首次使用需安装依赖
node server.js     # 启动服务
```

看到以下输出即成功：

```
多平台发布器已启动: http://localhost:8800
CDP 调试端口: http://127.0.0.1:9222（浏览器需以 --remote-debugging-port=9222 启动）
```

浏览器打开 **http://localhost:8800**。

### 2.2 准备浏览器（关键步骤）

程序通过 **CDP 调试端口（9222）** 接管浏览器。页面右上角提供两种模式：

| 模式 | 特点 | 前提 |
|------|------|------|
| **独立 profile（默认，推荐）** | 启动一个专用浏览器窗口，与你的日常 Chrome **完全隔离、互不影响** | 点「拉起浏览器」即可，但**需要在这个专用窗口里登录一次各平台** |
| **复用日常 profile** | 直接用你日常 Chrome 的登录态，**无需重新登录任何平台** | **必须先彻底退出 Chrome**（含托盘、后台进程），否则调试参数会被丢弃 |

**操作顺序**：

```
① 选模式 → ② 点「拉起浏览器」→ ③ 等弹窗提示"端口就绪"
   → ④ 点「连接浏览器」→ ⑤ 点「检测登录态」
```

- 选**独立 profile**：在弹出的专用浏览器里，把要用的平台各登录一次（只需一次，之后会一直记住）。
- 选**复用日常 profile**：先完全退出 Chrome，再点「拉起浏览器」，它会带着你的登录态启动。

> **为什么必须这样**：Chrome 有单实例机制——浏览器已在运行时，新启动实例的调试端口参数会被忽略。
> 另外 Chrome 136+ 起必须显式指定用户数据目录。

## 3. 日常使用五步走

### 第 1 步：填写文章

- **标题**：输入文章标题。右侧平台列表会显示各平台标题字数要求。
- **正文**：支持 **Markdown**。图片用标准语法 `![说明](图片URL)`。

支持的 Markdown 语法：`# 标题`、`**加粗**`、`*斜体*`、`- 列表`、`1. 有序列表`、
`> 引用`、表格、`![图](url)` 等。

### 第 2 步：勾选目标平台

右侧「目标平台」列表默认全选，按需取消。勾选**贴吧**时会多出「贴吧吧名」输入框，必填。

输入过程中会自动校验，不合规项实时显示（红色为阻断错误，黄色为提示）。

### 第 3 步：选择发布模式

| 模式 | 行为 | 适用场景 |
|------|------|----------|
| **保存为草稿**（默认，推荐） | 内容填入各平台编辑器并保存在**草稿箱**，**不对外发布** | 想先各平台预览、微调后再发 |
| **直接发布** | 点各平台的发布/群发按钮 | 确认内容无误、要立即上线 |

> ⚠️ **「直接发布」模式下，微信公众号是群发操作，推送后不可撤回**。首次使用强烈建议先用草稿模式。

### 第 4 步：点「开始发布」

任务进入队列**串行执行**（一个平台完成后才处理下一个，降低平台风控风险）。
下方「发布进度」面板实时显示每个平台的结果。

### 第 5 步：处理结果

| 结果 | 你需要做什么 |
|------|--------------|
| ✅ **已保存草稿**（微信/头条/知乎/百家号/小红书） | 到对应平台草稿箱检查、微调后手动发布 |
| ⏸ **已填写待手动提交**（贴吧/微博） | 这两个平台**无草稿功能**，需你到浏览器窗口手动点「发布」/「发送」 |
| ❌ **失败** | 点任务上的「重试」；若反复失败，查看截图定位原因（见第 7 节） |

## 4. 界面说明

### 顶部工具条

| 按钮 | 作用 |
|------|------|
| **连接浏览器** | 连接已带调试端口启动的浏览器 |
| **拉起浏览器** | 按所选模式启动浏览器（自动带上调试端口） |
| **诊断** | 连接失败时点击，给出具体原因（运行中的浏览器数、调试端口进程、profile 状态等） |
| **检测登录态** | 逐平台检测登录状态，未登录的平台会提示 |
| 连接指示灯 | 绿=已连接，灰=未连接 |

### 左侧编辑区

标题输入框、正文（Markdown）、贴吧吧名（勾选贴吧时显示）、字数统计、模式选择。

### 右侧面板

- **目标平台**：平台勾选 + 规则提示 + 校验结果 + 「开始发布」按钮
- **发布进度**：任务列表（状态、消息、截图链接），支持「重试」和「清除已完成」

## 5. 各平台规则速查表

| 平台 | 标题字数 | 正文字数 | 图片要求 | 草稿支持 |
|------|---------|---------|---------|---------|
| **微信公众号** | ≤ 64 | ≤ 20000 | 外链图自动转存素材库 | ✅ 支持 |
| **今日头条** | 5 ~ 30 | ≤ 30000 | 建议 1~3 张 | ✅ 自动保存 |
| **知乎** | 1 ~ 100 | ≤ 100000 | 无特殊要求 | ✅ 自动保存 |
| **百家号** | 8 ~ 30 | ≤ 30000 | 建议至少 1 张 | ✅ 支持 |
| **小红书** | 1 ~ 20 | **≤ 1000** | **必须 ≥ 1 张** | ✅ 支持（暂存） |
| **百度贴吧** | 5 ~ 31 | ≤ 30000（建议 200~2000） | 最多 9 张，仅 png/jpeg | ❌ 需手动发布 |
| **新浪微博** | 无独立标题 | ≤ 2000 | 最多 9 张 | ❌ 需手动发送 |

> 表中为程序内置校验规则。平台规则可能调整，**最终以各平台编辑器自身校验为准**。

## 6. 各平台注意事项

### 微信公众号
- 正文外链图会**自动下载并转成 base64**，粘贴后微信编辑器会**自动转存到素材库**并替换成微信 CDN 地址。
- 「直接发布」是**群发**，粉丝可见且**不可撤回**。
- 需先登录 mp.weixin.qq.com 后台。

### 今日头条
- 无独立「存草稿」按钮，编辑器**自动保存**（左下角显示「草稿已保存」）。
- 后台可能弹出新手引导、AI 助手侧栏；程序会自动关闭这些遮挡元素。
- 后台有时显示「我知道了」提示条，属于正常现象。

### 知乎
- 草稿依赖编辑器**自动保存**，填入后等几秒即入库。
- 正式发布时知乎可能弹出话题选择、封面确认弹窗，需你手动处理。

### 百家号
- 若后台弹新手引导/公告弹窗，**需先手动关掉一次**，否则可能影响流程。
- 发布后需经平台审核。

### 小红书
- **正文不支持富文本**：程序按**纯文本**提交，Markdown 图片语法会被剥离（图片走独立上传通道）。
- **网页端发布必须至少 1 张图**，否则无法发布。
- 正文限 **1000 字**，内容长时建议单独准备精简版。
- 草稿保存在**浏览器本地**（清除浏览器数据会丢失，最多 100 篇）。

### 百度贴吧
- **必须指定目标吧名**（勾选贴吧后填写），且吧必须真实存在。
- **无草稿功能**：草稿模式下只把内容填进编辑器，需你到浏览器里手动点「发布」。
- 图片仅支持 png/jpeg，单贴最多 9 张。
- 发布可能有审核延迟，吧内不一定立即可见。

### 新浪微博
- **无标题字段**：程序把标题并入正文首行显示为「【标题】」。
- 正文 **≤ 2000 字**（超过 140 字会折叠显示，属正常）。
- **无草稿功能**：需你手动点「发送」。

## 7. 常见问题排查

### Q1：点「连接浏览器」提示无法连接 / 端口未监听

1. 先点「**拉起浏览器**」，等提示端口就绪后再点「连接浏览器」。
2. 若仍失败，点「**诊断**」查看具体原因。
3. 选「复用日常 profile」时，**必须先彻底退出 Chrome**（任务管理器里确认没有残留 chrome.exe 进程）。

### Q2：检测登录态显示某平台「未登录」

到那个专用浏览器窗口里，打开对应平台官网登录一次即可（独立 profile 只需登录一次，之后长期有效）。

### Q3：某个平台发布失败，怎么定位？

1. 在「发布进度」面板点开该任务，查看**错误消息**和**截图**（截图保存在 `screenshots/` 目录）。
2. 常见原因：
   - **平台改版**：编辑器结构变化导致选择器失效 → 需更新适配器（`src/adapters/对应平台.js`）。
   - **弹窗遮挡**：平台弹出新手引导、公告、活动弹窗 → 手动关掉后重试。
   - **图片问题**：图片太小（< 1KB）会被平台静默丢弃；外链图失效会导致转存失败。
   - **内容超限**：标题/正文字数超限被平台拦截 → 按第 5 节表格精简。
3. 修复后点任务上的「**重试**」。

### Q4：图片没有出现在正文里

- 确认图片 URL **可公开访问**（不是本地路径、不是需要登录的图床）。
- 确认图片尺寸 > 1KB（过小的图会被平台丢弃）。
- 小红书、贴吧走独立上传通道，需等上传完成（程序已内置等待）。

### Q5：内容填进去了但平台没保存

- 头条/知乎**自动保存**有延迟，稍等几秒刷新草稿箱。
- 贴吧/微博**没有草稿**，必须手动提交。
- 小红书草稿存在浏览器本地，换浏览器/清缓存会丢失。

### Q6：想让某个平台发的内容不一样（如小红书要精简版）

当前一次任务对应一套内容。做法：**分两次提交**——
第一次勾选其他平台，第二次只勾选小红书，用精简版正文。

### Q7：服务重启后任务和登录态还在吗？

- **任务记录**：在（持久化于 `data/tasks.json`）。
- **登录态**：独立 profile 模式下登录态保存在 `data/browser-profile/`，重启浏览器仍在。

### Q8：能否新增其他平台？

可以。按 `src/adapters/` 下任一平台文件为模板新建适配器，实现登录检测与发布流程，
在 `src/adapters/index.js` 注册、在 `src/core/rules.js` 补规则即可。

## 8. 安全须知

1. **默认只存草稿**：默认模式不会对外发布任何内容，可放心试跑。
2. **群发不可撤回**：切换到「直接发布」后，微信公众号为群发操作，**发布前请二次确认**。
3. **不保存账号密码**：程序通过接管你已登录的浏览器工作，不接触、不存储你的账号密码。
4. **发布节奏**：程序已做**串行发布**降低风控风险，但仍建议**人工控制发布频率**，
   避免短时间内批量发布相同内容触发平台审核或限流。
5. **截图留证**：失败截图可能包含页面信息，保存在本地 `screenshots/` 目录，请注意不要外传。
